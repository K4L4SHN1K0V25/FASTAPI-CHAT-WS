# FastAPI Real-Time Chat 🚀

Un sistema de chat minimalista en tiempo real utilizando **WebSockets** y **FastAPI**.

## ✨ Características
- Comunicación bidireccional instantánea.
- Notificaciones de entrada/salida de usuarios.
- Frontend ligero con Bootstrap y Vanilla JS.
- Arquitectura asíncrona optimizada.

## 🛠️ Instalación
1. Clonar el repositorio.
2. Crear entorno virtual: `python -m venv venv`
3. Instalar dependencias: `pip install -r requirements.txt`
4. Correr servidor: `uvicorn app.main:app --reload`

## 💻 Tecnologías
- Python 3.12+
- FastAPI
- WebSockets
- Bootstrap 5
